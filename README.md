# Supper Club

A responsive Bengaluru food-delivery demo built with Flask, HTML, CSS, and vanilla JavaScript. Browse local favorites, search and filter dishes, save favorites, customize a bag, apply a welcome offer, choose delivery or pickup, and place a demo order with a confirmation status. Prices are shown in INR; checkout estimates delivery, packaging, and GST. Orders are simulated and no payment is collected.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5001. Checkout is simulated and does not collect payment. Food photography and web fonts load from Unsplash and Google Fonts.# food-delivery-website
